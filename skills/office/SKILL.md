# Office 文档（免费本地引擎）

这项能力不依赖托管额度。默认使用开源 Python 组件：

- Word：`python-docx`
- Excel：`openpyxl`
- PowerPoint：`python-pptx`

## 开始前

1. 运行下面的只读探针，不得在任务会话里联网安装依赖：
   `python -c "import docx,openpyxl,pptx; print('ready')"`
2. 如果探针失败，说明这台执行机缺少免费办公文档组件，引导机器所有者在 Runner 能力管理中补齐；不要自行改用收费服务。
3. 所有输入和输出只能位于当前工作目录。默认创建新文件，不覆盖原文件。

## 工作方式

- Word：使用标题层级、正文样式、页眉页脚和清晰表格；修改前先读取段落与表格结构。
- Excel：先识别工作表、表头和数据范围；设置数字、日期、公式、列宽、冻结窗格与筛选。
- PowerPoint：统一页面比例、主题、字号和留白；每页只表达一个重点，避免元素越界。
- 复杂视觉演示可同时使用 `pptx` Skill 的排版与渲染检查方法。

## 必须验证

每次交付新建或修改后的 DOCX、XLSX，都要对最终保存的文件运行检查器，无论使用哪种生成工具。从当前工作目录运行（将检查器路径替换为本技能目录下的实际路径）：

```sh
python "<Office 技能目录>/scripts/inspect_office.py" "报告.docx"
python "<Office 技能目录>/scripts/inspect_office.py" "预算.xlsx"
```

成功时读取标准输出的 JSON，将统计与本次交付要求逐项比对；文件损坏、格式不符或检查失败时命令以非零状态退出。
Word 统计正文（含表格单元格）中的段落、具有标题样式或大纲级别的标题、表格和 DrawingML 图片出现次数；页眉页脚单独检查。
Excel 按工作表列出已存储单元格及合并区域的包围范围、公式数量和合并区域；空表的范围为 `null`。此命令不修改文件，不计算公式。
`rendered: false` 表示仅检查文件结构；页数、分页、显示与打印效果需要另行验证。

完成后用对应开源库重新打开结果，并确认：

- 文件是有效的 Office Open XML 压缩包，不是空壳或伪扩展名；
- 页数、工作表数或幻灯片数符合要求；
- 标题、表头、公式、图片和备注真实存在；
- 输出目录没有锁文件、临时文件或测试副本。

最终回复列出成果文件、完成内容和“结构验收”。写出本次实测中与用户要求相关的项目和结果。需要区分一级、二级标题或确认标题文字时，用文档库重新读取并核对段落样式和文字；检查器仅报告标题总数。若检查失败或无法执行，如实说明原因。
