# Office 文档（免费本地引擎）

这项能力不依赖托管额度。默认使用开源 Python 组件：

- Word：`python-docx`
- Excel：`openpyxl`
- PowerPoint：`python-pptx`

## 开始前

1. 运行下面的只读探针，不得在任务会话里联网安装依赖：
   `python -c "import docx,openpyxl,pptx; print('ready')"`
2. 如果探针失败，说明这台执行机缺少免费办公文档组件，引导机器所有者在 Runner 能力管理中补齐；不要自行改用收费服务。
3. 所有输入和输出只能位于当前工作目录。默认创建新文件，不覆盖原文件。

## 工作方式

- Word：使用标题层级、正文样式、页眉页脚和清晰表格；修改前先读取段落与表格结构。
- Excel：先识别工作表、表头和数据范围；设置数字、日期、公式、列宽、冻结窗格与筛选。
- PowerPoint：统一页面比例、主题、字号和留白；每页只表达一个重点，避免元素越界。
- 复杂视觉演示可同时使用 `pptx` Skill 的排版与渲染检查方法。

## 必须验证

完成后用对应开源库重新打开结果，并确认：

- 文件是有效的 Office Open XML 压缩包，不是空壳或伪扩展名；
- 页数、工作表数或幻灯片数符合要求；
- 标题、表头、公式、图片和备注真实存在；
- 输出目录没有锁文件、临时文件或测试副本。

最终回复只列出用户可用的成果文件、完成内容和验证结论。
