# 单个即用图标

默认：只做当前即用的一个彩色图标；不是侧边栏家族、整套图标或配色展示板。

思路：核心用途/角色 → 一个直观隐喻 → 圆润实体 → 少量叠层 → 小尺寸辨识。精致、亲和、有记忆点；避免通用四宫格、细碎装饰、厚重3D。

形体：正方形画幅；光学居中、饱满、不窄；控制两侧留白；圆角与层次协调；主体轮廓一眼可认。

颜色：按业务、角色、题材选择；不限现有蓝紫黄；主色＋少量辅助色；轻渐变/柔和高光可选，不靠复杂阴影维持辨识。

自检：16/24/32/48/128px、白/灰/黑背景；缩小不糊、不挤、无多余底板。参考图用于提炼方法，不机械复制构图或固定配色。

交付：顶层 icon＝内嵌 PNG，≤256px、≤96KB；保留透明背景及必要边缘间距；SVG 源文件可随包。默认不生成灰色线条版、不扩成一整套；用户明确要求时再扩展。
