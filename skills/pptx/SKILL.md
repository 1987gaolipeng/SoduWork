# 演示文稿

交付真正可编辑的 `.pptx`。先明确受众、使用场景、需要传达的结论及已有模板；已有材料足够时直接制作。保留来源与待核实事项，避免把估算写成已验证事实。

## 工具与文件

优先使用执行环境已有的演示文稿工具。Python 环境可用 `python-pptx` 创建和修改；包名为 `python-pptx`，导入名为 `pptx`。仅在当前环境缺少且任务允许安装依赖时，在工作目录虚拟环境安装，避免改变全局 Python。

- [官方入门与示例](https://python-pptx.readthedocs.io/en/latest/user/quickstart.html)
- [官方 API](https://python-pptx.readthedocs.io/en/latest/api/index.html)

修改现有文件时先读取页数、尺寸、文本、图表和布局，另存候选文件。精确修改指定页和文字 run，避免用整页文本赋值破坏原有字体层次。不要删除不理解的形状、嵌入媒体、备注或动画。库无法可靠保留的功能，使用本机 PowerPoint 或已有原生工具，并明确验证范围。

## 设计与制作

按信息的因果和比较关系安排页面，不套固定页数。沿用用户模板；没有模板时使用一致的网格、字号层级、留白和少量强调色。复杂内容分步展示。文字、数据图表与表格保留可编辑对象；照片和视觉素材才使用图片。图表标注单位、时间及来源，不用装饰掩盖信息。

将生成脚本与成果放入本次工作目录，使用相对素材路径。新文件写到临时候选后重新打开确认，再输出最终文件名。对已有 PPTX 进行修改前保留原件。

## 验证与交付

运行随附的只读检查脚本：

```text
python <本技能目录>/scripts/inspect_deck.py <候选文件.pptx>
```

脚本检查包可读性、页数、文字、表格、图表数量及越界对象；越界可能是有意的装饰，需要结合页面判断。它不渲染，不证明没有文字溢出或视觉遮挡。

使用执行环境现有的 PowerPoint、LibreOffice 或演示文稿渲染器预览所有页面，检查换行、字体替换、文字遮挡、图片裁切、图表标签和色彩对比。LibreOffice 已安装时，可以用独立输出目录导出 PDF，再用可用的 PDF 查看工具逐页检查；不要伪造截图。没有渲染工具时明确标记“结构已检查，视觉未验证”。

交付最终 PPTX、必要的预览和简短的检查结果。修订任务说明实际修改的页；涉及素材、字体或特殊媒体时说明接收者需要的条件。
