# 连接器图标与来源

产品名称、连接器标识和授权方式由业务逻辑保留，图形只负责辅助识别。界面继续使用 28 × 28 图标，不通过远程图片请求加载素材。

- `category-*.svg` 是 SoduWork 独立绘制的 7 个功能类别图标，采用随附 `LICENSE.original-icons.txt` 中的 MIT 许可。它们没有描摹对应产品标识，不代表平台合作、认证或背书。
- 其余 46 个产品图形保留原有来源记录与 `LICENSE.simple-icons.md`。Simple Icons 集合的 CC0 版权说明**不授予产品商标权**；使用产品图形仍应核对权利人的品牌规范，不能把集合许可视为品牌方授权证明。
- `sources.json` 中 `artworkOrigin` 区分原创类别图标与第三方集合；原创条目的 `source` 链接用于查阅产品文档，不是图形来源。
- `previousArtwork` 只记录被替代图形的原来源、许可字段和未分发状态，以保留审计线索。对应旧图形已从本目录删除，不随新版分发；历史发布包不在此次改动范围。

目前 16 个产品采用原创类别图标：企业微信、钉钉、飞书、语雀、Runway、可灵、火山方舟、腾讯会议、腾讯云、火山引擎 ECS、Microsoft Excel、Teams、OneDrive、SharePoint、Azure 和 Outlook。原来标为 `custom` 或 `Product trademark` 的字段不再作为图形再分发授权依据。

引入新图形时，应先记录版权来源与适用品牌规范；不能确认时使用现有原创类别图标。不能仅因官网可下载图片，就认定允许把图片随软件再分发。
