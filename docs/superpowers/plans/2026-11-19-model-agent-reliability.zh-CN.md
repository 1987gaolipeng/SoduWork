## 再次独立验证

第二轮查出并补修了新的遗漏：探测显式携带 `tool_choice: auto`，与真实 Pi 续答不同；一般 403 分类会跳过独立检测；仅有历史 verified 记录的旧证据在两端投影不同；Windows 带引号及正斜杠 PATH 处理不完整；Node 子进程可能继承另一份安装；DSH 原生依赖按 Python 而非所选 Node 判断架构；自定义 wrapper 与 shebang 启动行为可能被丢弃。现在启动环境按最终命令参数绑定，不再重新发现安装，也不修改全局 PATH；只改写已核对的标准 npm shim 和纯 Node 入口，其他 wrapper 保留原命令。

- 全量客户端：10,132 项，10,123 通过、9 跳过、零失败。随后能力／会话相关 208 项、语言检查 116 项通过；最终启动修改完成后，依赖 Python 的客户端 13 项也已重新执行并通过。
