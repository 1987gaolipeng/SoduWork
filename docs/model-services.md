# 模型服务、协议与计费

**简体中文** · [English](model-services.en.md) · [文档目录](README.zh-CN.md)

在**我的模型**中配置供应商的 API 地址、接口协议、模型 ID 和对应凭据。凭据保存在当前设备的服务，由桌面主进程发起连接和能力检测；由 Hub 管理的服务，则由 Hub 发起检测。因此，本机服务的 `127.0.0.1` 指向桌面电脑，Hub 管理服务的 `127.0.0.1` 指向 Hub 所在电脑。应填写发起请求的电脑能够访问的地址。

## 平台额度与个人模型

以下续作与个人用量豁免适用于默认 Pi 的模型对话通道；其他执行底座、图像/视频生成和独立视觉转录服务继续使用原有额度规则。Pi 将图片直接交给当前聊天模型时，沿用该聊天模型的规则。平台 Token 额度适用于使用组织共享凭据的模型。使用你在“我的模型”中保存的个人 API Key，或你添加的免密钥自部署服务时，新的、经 Hub 验证的用量仍会保留在用量记录中，但不扣减平台 Token 额度。组织配置的免密钥服务不会自动获得个人模型豁免。个人 API Key 对应的供应商费用仍由你承担。

平台总额度或单模型额度耗尽后，可以在原会话的模型菜单中选择账号允许使用的个人模型，再发送继续完成任务的请求。切换只影响之后提交的轮次；正在执行和已经排队的轮次不会自动换模型。已完成的对话和工具结果会保留，但中断的生成不会自动续接，继续前应检查已生成文件和已执行操作。

个人模型仍须通过账号、设备和模型访问检查。账号停用、管理员将 AI 额度明确设为零、试用到期，以及套餐中不允许使用的模型，仍然会被阻止。平台额度与供应商余额是不同限制：供应商返回余额不足时，需要处理该供应商的账户或凭据。

此行为需要配套更新 Hub 和桌面客户端，并执行数据库迁移。旧版或无法验证归属的用量保持原有计入规则，不会根据当前模型配置重新归类历史记录。仅在客户端填写“个人模型”标记不能获得额度豁免。

## 连接测试能证明什么

在网页管理端，进入**模型目录 → 接一个服务**配置组织模型服务。保存前可点击**测试连接**，Hub 会使用表单中的配置读取供应商的模型列表。列表可以成功返回零个模型。保存后，可在已配置的服务卡片点击**加第一个模型**，按模型 ID 添加。要配置日报总结和旧版执行所用的模型，请进入**展开概览 → 目录配置 → 组织默认调用（旧版兼容）**。

在客户端，**保存并测试连接**首先读取供应商的模型列表。列表请求成功只验证该接口可访问，不代表聊天生成已获授权、计费余额充足，也不代表所选 Agent 支持该协议。模型列表接口不可用时，测试可能发送一个最小聊天请求，产生相应用量。结果会说明哪种测试成功。

当前企业模型对话通道使用 OpenAI 兼容接口。Anthropic 服务可以保留给支持它的 Agent，但 Anthropic 连接测试通过不会让它兼容此通道。模型编辑页和企业模型选择器会在执行前提示这个限制。只更改协议选项不会转换供应商接口；应使用供应商提供的对应地址和密钥。

## 模型能力检测

在客户端“我的模型”中，先保存模型服务，再填写模型表单并点击“添加模型”。这个按钮只保存当前新增的模型。服务名称、地址和密钥的待保存修改仍由上方的“保存”按钮提交。

在客户端添加对话模型或在网页“模型目录”中保存新增的对话模型后，已启用且配置完整的 OpenAI 兼容服务会使用已保存的设置，在后台进行首次能力检测。同时添加多个模型时，符合条件的模型会逐个检测。再次打开模型目录时会读取已保存的报告，也可以在模型行点击“检测能力”重新检测。

**检测能力**会针对已保存的具体模型发送少量真实生成请求，分别验证文本回复、识别随机生成图片中的数字、模拟函数调用及其安全回执，以及完整的流式文本回复。如果服务商对流式请求明确返回不支持工具，Hub 会去掉流式和可选参数后重试。只有模型正确返回预期的工具结果，工具调用检测才会通过。检测不会执行系统工具，但可能产生供应商用量。读取模型列表属于独立的发现流程，不能证明这些能力。

目前自动检测覆盖 OpenAI 兼容的 Chat Completions API。其他协议族保持未确认，不能仅凭协议名称或模型名称认定支持。只有供应商明确拒绝可选参数时，才会进行有限的兼容参数协商。通过结果仅适用于当前地址、凭据、模型和请求配置，不能证明其他 API 协议族或所有 Agent 执行底座都可用。

能力标签区分手动声明与实测结果。手动声明优先；与确定的实测结果不一致时，会提示冲突。检测详情记录最近一次尝试。未能确认时，保留已有的支持结论。使用自动图片路由时，只要该模型在相同配置下成功识别过图片，即使后续检测明确拒绝图片，对话仍可向它发图。详情会显示本次拒绝和上次通过的时间。工具调用和流式输出在检测明确返回不支持时更新为不支持。本机检测可以取消，关闭模型面板也会取消；请求具有时间、大小和重试上限。

旧版工具调用和流式输出的结果需要重新检测，因为它们没有验证当前检测要求的完整工具交互或流结束状态，也可能把可选参数被拒绝误判为能力不支持。手动声明和仍适用的图片检测结果会保留。

修改接口地址、凭据、模型 ID、协议或请求策略，会使对应证据失效并取消过期检测。修改显示名称、备注或手动能力声明会保留实测证据。本机结果仅加密保存在当前设备，本地凭据与本地能力检测不会转发到 Hub。重新打开应用会恢复仍匹配配置的结果。证据无法解密或读取时，模型目录仍可使用，能力显示为未确认；重新检测会重建证据存储，并备份不可读的加密数据。

运行时会使用相应的原生图片路由、输出上限和受支持的兼容选项。Pi 需要流式接口；明确要求工具能力的操作，会拒绝已声明或已确认不支持工具的模型。能力未知时保持既有执行行为。更新作用于后续模型选择或轮次，不会改变已在执行的请求。上线前仍应使用目标部署中的供应商和执行底座进行验收。

## 工具已完成，模型拒绝下一次请求

在使用 OpenAI 兼容聊天补全服务的 Pi 对话中，模型可能接受普通消息，却在收到工具结果时返回 HTTP 403。打开对话中失败请求的详情，可查看当时使用的模型和请求阶段。对已保存的模型运行能力检测，可分别检查普通文本、流式输出和模拟工具调用。若没有检测企业模型的权限，请联系管理员。

如果对话提供「切换模型并总结已有结果」，可先选择其他对话模型，再使用该操作总结已确认的产物和剩余工作。总结过程中禁用工具，已经写入的文件和原任务的执行结果会保留。对于经 Hub 转发的请求，此操作需要 Hub 支持识别上游返回的通用拒绝。遇到明确的权限或策略拒绝时仍会停止。

## 智谱 GLM 接口与错误码 1113

智谱为标准 API 和 Coding Plan 提供了不同的接口及凭据。[官方配置文档](https://zcode.z.ai/cn/docs/configuration)列出了：

| 产品与协议 | API 地址 |
| --- | --- |
| 标准 API，OpenAI 兼容 | `https://open.bigmodel.cn/api/paas/v4` |
| Coding Plan，OpenAI 兼容 | `https://open.bigmodel.cn/api/coding/paas/v4` |
| Coding Plan，Anthropic | `https://open.bigmodel.cn/api/anthropic` |

请按照供应商当前文档核对订阅、API Key 类型、接口地址和模型。Coding Plan 还限制受支持的工具和产品场景，修改接口地址并不代表 SoduWork 已获得使用资格。资格和计费规则请参阅[官方 Coding Plan 常见问题](https://docs.bigmodel.cn/cn/coding-plan/faq)。

供应商返回错误码 `1113` 或已识别的余额/额度不足类型时，SoduWork 会显示计费问题，并只保留允许公开的诊断码。自动重试会停止，因为重试不能补充余额或改变订阅。请先核对供应商账单和 API Key 类型。没有已识别计费码的普通限流 `429` 仍可按既有上限重试。

这些诊断不会显示原始上游错误正文、凭据或内部地址。模拟供应商的本地回归通过只能验证上述行为，不能验证某个付费账户的余额或使用资格。
